# Birthday Website — Shita

Versi V1 dari website HBD yang kita rancang.

## Cara menjalankan
1. Buka `index.html` di browser.
2. Untuk musik, masukkan file MP3 ke:
   `assets/music.mp3`
3. Kalau nama konser/venue sudah fix, edit bagian tiket di `index.html`.

## Struktur
- `index.html` — semua screen
- `style.css` — visual + animasi
- `script.js` — navigasi + interaksi
- `assets/music.mp3` — musik opsional

## Alur
Opening → Gift 1 → Gift 2 → Nonton Bareng → Birthday Wish → Closing
